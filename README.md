# Colorado State University ECE537 Project

### Compressed Sensing Electrocardiogram (CSECG)
This directory contains python sources relevant to the implemntation of Compressed Sensing for ECG Signals.

From the `csecg` directory:
```
python -m pip install -e .
python scripts\download_dataset.py
python scripts\main.py
```

### Paper
This directory contains LaTeX sources for compiling the accompanying research paper.

From the `paper` directory:
```
make
```
